O que essa tela faz Em vez de cadastrar um conhecimento por vez, aqui você importa vários de uma só vez a partir do código de um sistema legado. O processo tem 3 passos: copie o prompt abaixo, rode ele com uma IA de código (Claude Code, Cursor, etc.) dentro do repositório do sistema legado, e envie o .zip com os arquivos gerados no campo mais abaixo. Cada arquivo vira um conhecimento pendente, que passa pela mesma aprovação de sempre antes de entrar na base do Agente.
Como usar o prompt Copie o texto abaixo e cole numa ferramenta de IA com acesso ao código do sistema legado (Claude Code, Cursor ou similar), rodando dentro da pasta do repositório. A ferramenta vai ler o código, identificar os módulos e comportamentos relevantes pra suporte e treinamento (guias de telas, conceitos e fluxos, além de diagnósticos de problemas), e gerar uma pasta com um arquivo .md por conhecimento, já pronta pra ser compactada em .zip.
